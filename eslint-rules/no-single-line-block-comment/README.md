# no-single-line-block-comment

1行で書かれたブロックコメント（`/** ... */` および `/* ... */`）を禁止し、複数行のスター付きブロックコメントへの展開を強制する。

## 背景

1行に詰め込んだブロックコメントは、追記時に整形が崩れやすく diff も読みにくい。複数行へ展開して各行を `*` 揃えにすることで、JSDoc としての見た目も統一する。

## 例

```ts
// NG
/** ユーザーを取得する */
const getUser = () => {};

// OK（自動修正後）
/**
 * ユーザーを取得する
 */
const getUser = () => {};
```

`/* ... */`（非 JSDoc）も対象で、`/*` を維持したまま複数行へ展開する。

## 除外対象（報告しない）

- `eslint` / `@ts-` / `prettier-ignore` / `biome-ignore` などのディレクティブコメント（展開すると構文上の意味が壊れるため）
- 同一行にコードが存在する行中インラインコメント（例: `fn(/* x */ 1)`、`const a = 1; /* メモ */`）
- 中身が空のコメント

## 自動修正

`--fix` で複数行へ展開する。`--fix-type` を指定する場合は `layout` を含めること。
