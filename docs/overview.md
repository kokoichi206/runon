## 現状の機能（実装済み）

### A. 周回路 / 距離計算（`/`）

- 論文 Lewis & Corcoran 2024 の「等時線多角形法 + 多目的パレート局所探索」を TS 実装
- OSM/Overpass 取得 → 有向グラフ → Dijkstra。**detour 補正**（実距離/周長を実測して周長を調整）＋
  各候補の再スケールで、全候補を**目標距離 ±約10%以内**に（例: 10km→全候補 9.8〜10.2km）
- 多目的: f1=距離誤差 / f2=区間重複%。パレートフロント + 方位別の別方向候補
- 描画: MapLibre(キー不要 OSM タイル)。選択経路=太線/他候補=薄線、始点マーカー
- 始点指定: 地図クリック / 緯度経度 / プリセット / **現在地(GPS→失敗時 IP 概算)** / **自宅登録(localStorage)**
- エクスポート: **GPX をスマホに送る/保存(Web Share)**、Google マップ近似リンク(経由地点を RDP で曲がり角優先)
- プロファイル walk 固定（ランニング想定。API は bike も受付）

### B. トレーニング計画（`/training`）

- 取込: **Garmin CSV** / **Strava 連携(OAuth, 任意)**
- 走力推定: 週間距離・最長走・イージーペース・**現VDOT(≈VO2max)**・**最大HR(自動検出)**
  （VDOT は最大HRがある時「追い込んだ走」優先で精度UP）
- 生成: 期分け(基礎→構築→ピーク→調整)でロング走を漸進。**最長走×2+2km の安全上限**
- 週設定: 練習可能な曜日 + **週の練習回数(分散選択)** + 確保時間(距離を時間でキャップ)
- 各日: 距離・推定時間・**ペース(@x:yy/km)**・**HRゾーン(Z1–5)**・**週1のポイント練習★**
- 目標タイム → **VDOT(Daniels) からペース設計**、「**目標と伸ばし方**」(現状VDOT→目標, 実現可能性)
- スキップ / 今週スキップ / 再計算(今日起点)
- 共通: ヘッダーナビ、設定は localStorage 保存

## 既知の制約

- Google マップ(一般アプリ)は任意ラインのナビ不可 → 正確なナビは GPX + 専用アプリ(OsmAnd/Komoot/Garmin)
- VO2max は数値ソースが無く**推定**(VDOT)。最大HRは実測テスト無しの**観測値**で近似
- 周回路の計算は密な市街地・長距離で重い(東京 10km で約15秒)
- Overpass はフェアユース(公開エンドポイント)。多用時は自前/キャッシュ推奨
- 保存はブラウザ単位(端末/ブラウザ間で共有されない)
- Strava 連携は**キー設定で有効化**(未設定なら未連携表示)。実トークン交換は要キー検証
