複数経路の比較 UI 4案

4案とも 同じ「摘んでドラッグできるボトムシート」（peek / mid / full の3段スナップ）の上に、異なる経路比較の見せ方を載せています。地図には候補3本（A=オレンジ/B=シアン/C=バイオレット）。

操作: 各プレビュー内で シート上端のハンドルを摘んで上下にドラッグ（タップでも開閉）。地図のループやチップ/カードを操作して挙動を確かめてください。 じっくり触る案は 「全画面で開く」 から。気に入った番号（や「Cベース＋Aの比較ボタン」等の組合せ）を教えてください → 本実装に落とします。
案 A
比較 ↔ フォーカス トグル

「比較｜選択中」の2状態。既定は3本色分け表示、選ぶと選択ルート太線＋他ゴースト。"選択あればそれ・なければ全部"にそのまま沿う。

長所
  • 2状態だけで迷いにくい
  • 地図タップとチップが同じ選択に収束
  • 選択中は数値を大きく＋決定操作が最短
注意
  • 3件の数値一括比較は表型に劣る
  • 往復でモード遷移が挟まる

案 B
スワイプ・カルーセル

下部に1枚ずつ大きいルートカード。スワイプで地図フォーカスが追従（選択=太線/他=ゴースト）。一度に1件で最小ノイズ。

長所
  • 1画面1件で最もごちゃつかない
  • 「すべて比較」で全体把握も可
  • カード内で意思決定が完結
注意
  • 厳密な数値並列比較は往復が必要
  • 横スワイプと縦ドラッグ/スクロールの取り違え
全画面で開く ↗
案 C
地図レジェンド・オーバーレイ

地図主役で3本常時表示＋最小フローティング・レジェンド。行タップでフォーカス、シートは既定PEEKで小さく。地図を最大に見せる。

長所
  • 形状・位置を重ねて直感比較
  • 地図占有が最大
  • 「比較」で必要時だけ数値展開（段階開示）
注意
  • レジェンドがルートに干渉する余地
  • フォーカスとシート展開の2状態の学習
全画面で開く ↗
案 D
ランク付きリスト + 個別表示トグル

順位リスト（Aは大型カード、B/Cはコンパクト行）。各行の👁で地図描画をON/OFF、方位フィルタつき。比較表に近い精密派向け。

長所
  • 順位・距離・重複・誤差・方位を一覧
  • 地図に描く線を個別/一括制御
  • 方位フィルタ＋状態整合が崩れない
注意
  • 操作軸が多く初見で把握しづらい
  • 未選択行から直接共有は1タップ余計
